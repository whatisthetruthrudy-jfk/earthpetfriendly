# earthpetfriendly

Independent static pet product discovery website inspired by the category structure of Lighter Home Goods.

## Contents

- 12 categories, each with 12 distinct product ideas (144 total).
- Amazon search links tagged with `lighterhomego-20`.
- Responsive layout, category search, affiliate disclosure, guides, and policy pages.
- Real Pexels lifestyle photography, an original paw-and-leaf logo, and a cream, turquoise, peach, and yellow palette. Photos do not show exact Amazon product listings.

## Preview and hosting

Serve this folder with any static web server. Publish the repository root as the website directory; no build step is required. Links use paths from the website root, so host on a domain root rather than a subdirectory.

## Affiliate setup

Register the final live URL in the owner's Amazon Associates website list. The current tag is shared with the owner's other website. Replace it across the category HTML files with an Amazon-issued pet-specific tracking ID if separate reporting is desired.

Links currently open Amazon search results for product types. Product photographs are matched to 144 named manufacturer products. Exact Amazon listings, prices, and availability have not been verified. Manufacturer photo reuse permission remains unverified; this package is for local review pending clearance for public commercial publication. Commissions depend on Amazon's qualifying-purchase and attribution rules.

Uploading to GitHub does not deploy the website or register a custom domain.
